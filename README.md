# Incredible Corporate Communications — Case Studies

Premium editorial case studies frontend built with React, Vite, Tailwind CSS v4, React Router, Motion, Recharts and Lucide React.

## Requirements

- Node.js 20.19+ (Node.js 22 recommended)
- npm 10+

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Routes

- `/case-studies` — case studies listing
- `/case-studies/kamal-matta` — Kamal Matta case study
- `/contact` — contact destination placeholder pending approved contact details

## Asset notes

- `public/assets/kamal/kamal-profile-crop.jpg` is a crop of the genuine profile photograph visible in the supplied LinkedIn post screenshot. A high-resolution original portrait should replace it when supplied.
- `public/assets/linkedin-posts/letter-to-my-daughter-post.png` is the supplied salary-structure LinkedIn post screenshot.
- The original post screenshots for Kolhapuri Chappal vs Prada, Paytm/InMobi, spine injury, and India–UK FTA were visible in the project brief/screenshots but were not separately available as source image files in the working asset folder. Their gallery entries must use the originals when those files are supplied; no fake LinkedIn screenshots are generated.
- No agency logo, official social profile URL, contact email, or booking link was supplied. The interface therefore uses a text-based wordmark and a contact placeholder rather than inventing brand/contact details.

## Reporting safeguards

- The 1.5M campaign-level figure remains labelled `reported campaign views` pending metric-definition confirmation.
- The two salary post impression figures (256,466 and 256,523) are preserved separately with their source distinctions.
- The 90-day analytics remain distinct from eight-month campaign-level results.
