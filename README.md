# InCredible Corporate Communications

Building Visibility, Keeping Credibility.

Official website of InCredible Corporate Communications.

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Installation

Clone the repository:

git clone https://github.com/AtharvaJayn/InCredible-Website.git

Navigate to the project:

cd InCredible-Website

Install dependencies:

npm install

Run the development server:

npm run dev

## Build

npm run build
